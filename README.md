# English Learning App 📚

A simple and interactive web application designed to help beginners learn and practice English.

The app provides lessons, quizzes, reading and writing practice, a basic English assistant, and progress tracking in one place.

## 🌐 Live App

[Open the English Learning App](https://english-learning-app-fambeffy8g2xphfkj7sycb.streamlit.app/#recommended-practice))

## 📌 Project Overview

The English Learning App is designed for beginner English learners. It allows students to create a profile, learn basic English concepts, practice their skills, and track their learning progress.

The application is built using **Python** and **Streamlit** and is deployed using **Streamlit Community Cloud**.

## ✨ Features

* 👤 **Student Profile**

  * Enter student name
  * Select English level
  * Set available study time

* 📖 **Learning Lessons**

  * Greetings
  * Pronouns
  * Simple Sentences
  * Present Simple

* 📝 **Practice**

  * English quizzes
  * Immediate feedback
  * Score tracking

* 📚 **Reading Practice**

  * Short English passages
  * Reading comprehension questions

* ✍️ **Writing Practice**

  * Simple writing exercises
  * Basic feedback

* 🤖 **Ask AI / English Assistant**

  * Provides help with common English questions
  * Gives simple explanations for beginners

* 📊 **Progress Tracking**

  * Completed lessons
  * Quiz scores
  * Vocabulary
  * Mistakes
  * Learning streak

## 🛠️ Technologies Used

## ▶️ Run the App Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the project folder

```bash
cd english-learning-app
```

### 3. Install the required library

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.

## 🚀 Deployment

The application is deployed using **Streamlit Community Cloud**.

The GitHub repository is connected to Streamlit Community Cloud, allowing changes pushed to the repository to be reflected in the deployed application.

## 🎯 Project Goal

The main goal of this project is to provide a simple and beginner-friendly platform for learning English.

Instead of using separate resources for lessons, practice, reading, writing, and progress tracking, the application brings these features together in one interface.
